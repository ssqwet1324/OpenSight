# OpenSight

Рабочий стенд для экспериментов: локальная нейросеть на компьютере, Go-сервис, ESP32-C3 с прошивкой на Rust и OLED 128×64. Сохранён как основа, из которой можно брать отдельные компоненты для следующих проектов.

## Что работает

- `POST /api/v1/ask` принимает вопрос, вызывает Ollama и возвращает ответ в JSON.
- Go отправляет тот же ответ на ESP через WebSocket.
- ESP подключается к домашнему Wi-Fi, восстанавливает соединение с сервером и отвечает на ping.
- OLED показывает русский текст по буквам, переносит слова и прокручивает шесть строк.
- Отдельный протокол готовых кадров позволяет внешнему плееру синхронизировать экран с видео: пауза и перемотка меняют содержимое экрана по времени плеера.

```text
Вопрос → Go → Ollama / Qwen → Go → WebSocket по Wi-Fi → ESP32-C3 → OLED
Внешний источник кадров → Go → тот же WebSocket → ESP32-C3 → OLED
```

Страница караоке, песня и её разметка — отдельный локальный эксперимент; в этом репозитории сохранена основная платформа.

## Структура

```text
lensService/          Go: HTTP API, клиент Ollama, доставка текста и кадров
opensight-firmware/   Rust: Wi-Fi, WebSocket, управление OLED
```

## Железо

- ESP32-C3 Super Mini с USB-C.
- Совместимый с SSD1306 OLED 128×64, I²C; проверенный адрес — `0x3C`, прошивка также проверяет `0x3D`.

| ESP32-C3 | OLED |
|---|---|
| GND | GND |
| 3V3 | VDD / VCC |
| GPIO4 | SDA |
| GPIO5 | SCK / SCL |

Подключать при отключённом питании. Сверять подписи выводов на конкретных платах; питать дисплей от 3,3 В. Сейчас это стенд с прямым просмотром OLED и питанием ESP по USB. Камера, микрофон, оптика и автономное питание не реализованы.

## Запуск

Проверено на Windows 11; прошивку также собирали в WSL Ubuntu. Для прошивки через Windows COM-порт используется PowerShell.

1. Поднять Ollama и установить модель `qwen3-vl:2b-instruct` либо указать другую установленную модель в конфигурации.
2. Настроить и запустить [Go-сервис](lensService/README.md).
3. Указать локальные настройки и собрать [прошивку ESP32-C3](opensight-firmware/README.md).
4. Разрешить доступ ESP к Go-сервису в домашней сети и отправить вопрос.

Настройки Wi-Fi, адрес компьютера, `.env`, бинарники и журналы не хранятся в Git. В репозитории есть шаблоны для нового запуска. Пароль Wi-Fi включается в локально собранную прошивку, поэтому готовые бинарники с настоящими настройками тоже остаются локально.

## Проверки

Из папки `lensService`:

```powershell
go test ./...
```

Из папки `opensight-firmware`, после создания локальных конфигурационных файлов:

```powershell
cargo build --locked
```

Для логики переноса текста и проверки протокола кадров есть независимые тесты, запускаемые на компьютере; команды приведены в README прошивки. Работа с OLED и Wi-Fi проверена на реальной ESP32-C3.
